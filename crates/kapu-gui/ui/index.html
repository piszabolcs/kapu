            Check the file

            The quick check reads the header and every derived section. The full check also reads the body: every fingerprint, every room marker, and whether a rebuild gives the same bytes.

            Read the sources again

            A file made here keeps its source list beside it (.sources.json). Reading them again updates the rooms; unchanged documents come from the cache, sections keep their ids, and rooms written by hand stay.

            Make a knowledge file

            Add web addresses, files and folders: PDF, Word, Excel, PowerPoint, OpenDocument, RTF, EPUB, HTML, Markdown, text, CSV, code, e-mail, ZIP and 7z archives, help files and images. They are read on this computer, cut into rooms by their headings and written into one .kapu file. Web pages are fetched from their own site; nothing is sent anywhere else.
